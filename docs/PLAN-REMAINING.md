## 四、风险控制

1. **白屏**：每次 UI 改动后必跑 `render-live.mjs`，要求两阶段 0 错误
2. **hook 顺序**：新增 useState/useMemo 必须在 early return 之前
3. **剧透门控**：第二纪元化身默认 tier 3（涉及结局），需正确标记
4. **数据不变式**：每幕恰好一个原著选项（selfcheck 守住）
