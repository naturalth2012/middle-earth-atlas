# 中土图鉴 · 指环王知识图谱

把《霍比特人》《魔戒》《精灵宝钻》原著、彼得·杰克逊电影三部曲和《力量之戒》剧集中的**人物、地点、宝物、术语、剧情与改编差异**，整理成一套可以在侧边栏里自由探索的知识图谱。

## 它能做什么

**十一个标签页，从不同角度进入中土：**

| 标签 | 内容 |
| --- | --- |
| 🧭 总览 | 数据规模、阵营分布、来源层级，以及一键跳转的快速入口 |
| 👤 人物图鉴 | 搜索 56 位角色；阵营 / 作品 / 身份三重筛选；档案抽屉含生卒、关系、地点、宝物、名句 |
| 🕸️ 关系图谱 | 力导向布局的交互式关系网络：拖动、缩放、聚焦、阵营高亮，外加关系路径查询 |
| 📜 时间线 | 从第一纪元到第四纪元的 33 个关键事件，可按纪元筛选 |
| 🏔️ 地点与宝物 | 27 个地点 + 14 件宝物，点开看相关人物与经手顺序 |
| 📖 术语与名句 | 9 条核心术语（迈雅、伊斯塔力、登丹人…）+ 40 句名台词 |
| 🗺️ 剧情与旅程 | 各作品主线分步速览 + 三条旅程路线 |
| 🌱 入门路线 | 新手 / 影视优先 / 深度考据三条导读路线 |
| 🎬 原著 vs 改编 | 10 处关键差异，避免把剧集演绎当成原著事实 |
| 💬 随手问 | 自然语言提问，答案来自同一套数据 |
| 🎭 化身之旅 | **扮演角色走进剧情**：14 位可扮演人物、43 幕场景、90 个抉择，见下方说明 |

**搜索是全域的**：输入「魔戒」会同时返回人物、地点、宝物、术语与作品分组结果。

## 🎭 化身之旅：走进故事里

这是与其他知识库最不一样的部分。选一个角色，回到他或她**真正面对抉择的那一刻**，做出你的选择，然后看看托尔金实际写了什么。

| 可扮演角色 | 主题 | 场景数 |
| --- | --- | --- |
| 弗罗多·巴金斯 | 重负与坚持 | 4 幕 |
| 比尔博·巴金斯 | 安逸与冒险 | 3 幕 |
| 索林·橡木盾 | 骄傲与和解 | 3 幕 |
| 山姆怀斯·甘姆吉 | 忠诚 | 3 幕 |
| 甘道夫 | 智慧与克制 | 3 幕 |
| 咕噜 / 斯米戈尔 | 欲望与分裂 | 3 幕 |
| 伊欧玟 | 勇气与身份 | 3 幕 |
| 阿拉贡 | 责任与忍耐 | 3 幕 |
| 波罗莫 | 荣誉与诱惑 | 3 幕 |
| 法拉米尔 | 清白与承认 | 3 幕 |
| 迪耐瑟 | 绝望与真相 | 3 幕 |
| 希优顿 | 衰老与觉醒 | 3 幕 |

**设计要点：**

- **每个场景都锚定真实事件**——不是编的，全部对应时间线里的具体条目与地点。
- **每个场景恰好一个"原著的选择"**，其余是合理的岔路。选完会告诉你原著怎么写、你的选择会通向哪里。
- **剧透控制**：可以只玩「开端」（等级 1）、含中段转折（2）或全部含结局（3）。选等级 1 时，涉及结局的场景根本不会下发到浏览器。
- **角色声音**：每位可扮演角色有一条"说话方式"提示，帮你进入语气。
- **结束后有评分**：判定你「与原著完全一致 / 大体忠于原著 / 走向了另一条路 / 完全偏离原著」，并逐幕列出你与原著的分歧点。
- **进度会自动保存**：刷新页面不会丢失，下次打开回到上次那一幕；走完一段旅程后存档自动清除，重新开始才是从头开始。
- **窄屏可用**：侧边栏拖窄到 720px 以下会自动切换单列布局，标签条改为横向滚动；全部控件可用键盘操作。

为什么不做成开放式对话？因为那样回答会脱离原著且无法验证——**代入感不该以讲错故事为代价**。这里的每一句叙述、每一个后果都是预先校订的，所以你怎么选，托尔金的原文都还在那里等你对照。

## 和对话打通

插件注册了 8 个工具，与面板共用同一套数据：

- `middle_earth_search` — 全库检索（人物 / 地点 / 宝物 / 术语 / 作品）
- `middle_earth_detail` — 任一实体的完整档案（角色含关系、地点、宝物、名句）
- `middle_earth_relation` — 两位角色之间的最短关系路径，逐跳标注关系
- `middle_earth_timeline` — 按纪元 / 作品 / 人物筛选时间线
- `middle_earth_graph` — 关系图谱统计、某人的邻居、或两点路径
- `middle_earth_ask` — 自由提问，返回基于数据的具体回答
- `middle_earth_play` — 开始一段化身之旅；不传角色名则列出可扮演的人，支持剧透等级
- `middle_earth_judge` — 给一段旅程打分，指出哪些抉择偏离了原著

在对话里直接问「弗罗多和咕噜是什么关系」「末日火山在哪里」「至尊魔戒」即可；
也可以说「让我扮演伊欧玟，只看开端」，体验化身之旅。

## 关于资料与来源标注

每条记录都带**来源层级**：

- **托尔金原著** — 《霍比特人》《魔戒》《精灵宝钻》及其附录
- **电影改编** — 彼得·杰克逊的《指环王》《霍比特人》三部曲
- **剧集演绎** — 亚马逊《力量之戒》，与原著出入较大，仅作为一种解读

「原著 vs 改编」页逐条列出阿尔温戏份、汤姆·邦巴迪尔、格洛芬德尔、阿索格血契、哈尔布兰德身份等差异。

由于本次构建环境的联网检索不可用，数据集基于广为人知的作品常识人工整理，未做在线逐条核对；细节请以原著与官方作品为准。

## 开发

```bash
node scripts/selfcheck.mjs   # 数据完整性 + 引擎行为 + 路由/清单校验（1550+ 项）
node scripts/probe.mjs       # 无浏览器渲染全部标签页，捕获元素树错误
node scripts/probe-drawer.mjs# 渲染四种档案抽屉的数据分支
```

## 使用

安装并启用后，点击左侧栏的「💍 中土图鉴」即可打开。

从 GitHub 或 npm 安装（发布后）：

```bash
dsh plugin --profile web add github:naturalth2012/middle-earth-atlas
dsh plugin --profile web add @naturalth2012/middle-earth-atlas
```
